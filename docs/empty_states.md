# Empty state illustrations

Each empty state has a matching SVG in `asset/illustrations/`. The set shares
a transparent background, rounded shapes, green outlines, and warm accents.

| Screen | SVG file | Empty state |
| --- | --- | --- |
| Dashboard | `dashboard-empty.svg` | No wallet exists yet |
| Catalog, items | `catalog-items-empty.svg` | No items exist |
| Catalog, categories | `catalog-categories-empty.svg` | No categories exist |
| Catalog, units | `catalog-units-empty.svg` | No units exist |
| Wallets | `wallets-empty.svg` | No wallet exists yet |
| Expenses | `expenses-empty.svg` | No purchase exists in the selected period |
| Reports | `reports-empty.svg` | No purchase report exists in the selected period |

The UI falls back to a themed inbox icon until each SVG is supplied.
